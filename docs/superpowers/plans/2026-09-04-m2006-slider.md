# M2006 Slider Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one fail-closed F407 image where PS2 right-stick horizontal drives one M2006 in both directions.

**Architecture:** A host-testable slider controller converts PS2 state, motor/CAN health, and two future limit inputs into target velocity and C610 current. A small ThreadX runtime owns the single M2006, feeds back output-shaft velocity, and sends control through the existing DJI handler.

**Tech Stack:** C++17, CMake/Ninja, ThreadX, existing remoter and DJI motor modules.

## Global Constraints

- Base the work on `e51a6f5` without modifying any `pnx_*` gitlink.
- Default to manual; Circle selects automatic and Cross selects manual.
- Automatic output stays zero until both limit sensors are explicitly marked ready.
- Any stale/invalid PS2, motor, CAN, or timing input produces zero current.
